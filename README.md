# Eventi a Bologna

Concerti, teatro, classica, rassegne e grandi eventi a Bologna e dintorni nei prossimi 12 mesi.

Sito: https://drdonatistefano-cmyk.github.io/eventi-bologna/

- `dati/eventi.json` — elenco eventi
- `scripts/template.html` — pagina
- `scripts/build.py` — costruisce `index.html` togliendo gli eventi passati
- `scripts/censimento_fonti.py` — verifica quali fonti offrono feed/calendari leggibili in automatico
- `.github/workflows/` — pulizia giornaliera e censimento
